# ELBOX — Bespoke Luxury Home Décor

Artisanal quiet-luxury home décor web store with catalog, filters, curated bag, and showroom private appointment booking.

## Quick Start (Installation & Execution)

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local development server:**
   ```bash
   npm run dev
   ```

3. **Open in browser:**
   Open [http://localhost:3000](http://localhost:3000) or [http://localhost:5173](http://localhost:5173) as indicated in the terminal.

## Build for Production

```bash
npm run build
```

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide React & Material Symbols
